# NexoLab

NexoLab es una aplicación móvil offline para cálculo científico, creación de modelos y simulación Monte Carlo.

## Qué incluye

- Calculadora científica con variables y funciones matemáticas.
- Modelo de fórmulas y parámetros guardados localmente.
- Simulación Monte Carlo con distribución normal, uniforme y triangular.
- Visualización de histogramas y métricas estadísticas.
- Modo claro y oscuro.
- Funcionamiento completamente offline.

## Requisitos

- Flutter SDK 3.3+
- Android o iOS

## Ejecutar

```bash
cd mobile
flutter pub get
flutter run
```

## Estructura

- `lib/main.dart`: lógica principal, interfaz y simulaciones.
