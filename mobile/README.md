# NexoLab Mobile

MVP offline en Flutter de una calculadora científica con modelos y simulación Monte Carlo.

## Ejecutar

```bash
cd mobile
flutter pub get
flutter run
```

No necesita internet durante el uso: las fórmulas y simulaciones se ejecutan en el dispositivo.

## Incluye

- Calculadora con variables, funciones trigonométricas y expresiones aritméticas.
- Modelos guardados localmente.
- Simulación Monte Carlo con distribuciones normal, uniforme y triangular.
- Histograma dibujado con Flutter CustomPainter, sin servicios externos.
- Modo claro/oscuro.

La carpeta raíz conserva el dashboard Streamlit original.
